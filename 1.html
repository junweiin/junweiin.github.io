docker 在centos7上的使用注意事项

去年买的一台腾讯云的轻量云还有两天到期了，下午找朋友借了身份，使新用户又重新买了一台轻量云，相比去年的月流量少了100个G。虽如此，做上线测试还有放了几个docker也是够用了。

然后想，每年都要折腾一次，也还是挺麻烦的，何不如把docker放在本地，家里的小服务器也可堪用的。遂研究起来，才发现，docker仅支持64位的系统，古早的i386不仅宝塔环境不支持，docker也不支持。折腾一番，白折腾了，记录下来，别下次再由此想法，重新折腾一遍。

阿里的镜像，网易的镜像都没有i386的安装包。

如何安装docker在centeos里，也很简单。

1 选一个快的镜像，比如阿里。

​yum install docker​

安装完成后，使用下面的命令来启动 docker 服务，并将其设置为开机启动：

​service docker start​

​chkconfig docker on​

CentOS 7中支持的新式 systemd 语法

​​systemctl​​ start docker​ ​.​​service​

​systemctl enable docker.service​

下载官方的 CentOS 镜像到本地， Docker 被墙 :-< ，所以请使用http://docker.cn 的镜像

显示当前正在运行容器的列表

​docker ps​
