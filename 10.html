继上次体验 Qwen3.5-9b 后，这次重点测试了不同上下文长度下的性能表现。

硬件配置

  • GPU: NVIDIA GTX 1060 14GB
  • 内存: 16GB
  • 平台: Windows + LM Studio 安装版

测试场景

场景一：中等上下文（54K）

配置参数：

  • 上下文长度：54,000 tokens
  • GPU 卸载层数：14 层
  • CPU 线程数：2
  • 其他参数：默认

表现：
在这个配置下，模型运行流畅，响应速度可接受。GPU 显存占用合理，系统整体负载较低。适合日常对话和中等长度的文档处理。

场景二：超大上下文（128K）

配置参数：

  • 上下文长度：128,000 tokens
  • GPU 卸载层数：2 层
  • CPU 线程数：2
  • 其他参数：默认

资源占用：

  • CPU 使用率：71%
  • 内存占用：12.5GB
  • GPU 使用率：90%

表现：
128K 上下文对硬件提出了更高要求。由于显存限制，大部分计算转移到 CPU，导致 CPU 负载显著上升。虽然仍能运行，但推理速度明显下降。GPU 保持高利用率，说明即使在少量层数的情况下，GPU 加速仍然关键。

总结

Qwen3.5-9b 在 14GB 显存的 GTX 1060 上表现还行：

  • 54K 上下文：平衡之选，速度与资源占用的最佳平衡点
  • 128K 上下文：可用但偏慢，适合对速度不敏感的场景

比Gemma4在洗车的问题上表现要好，起码没让我走着去洗车，O(∩_∩)O。
